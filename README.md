# RingOut Demo Day

기존 서비스 랜딩과 별도로 사용하는 데모데이용 정적 페이지입니다.
HTML, CSS, Vanilla JavaScript로 구성되어 의존성 설치와 빌드가 필요 없습니다.

## 로컬 실행

```sh
npm run dev
```

http://127.0.0.1:5173 에서 확인합니다. Python 3와 Node.js가 필요합니다.
문법 확인: `npm run check`

## 파일

- `index.html`: 소개, 서비스 이야기, 가설 검증, 기술적 도전 콘텐츠
- `styles.css`: 주황색 브랜드 디자인, 모바일 레이아웃
- `app.js`: 탭 전환, 방향키/Home/End 탐색, URL 탭 상태
- `favicon.svg`: 데모 페이지 아이콘
- `nginx.conf.example`: EC2 배포용 Nginx 설정 예시

`?tab=hypotheses#story`, `?tab=tech#story`로 특정 탭을 공유할 수 있습니다.
가설 검증 탭은 팀이 공유한 실제 실험 기록을 반영했습니다. 기술적 도전 탭은 아직 가상 사례입니다.
오전 사용 관측은 이벤트 단위의 기술적 결과이며 사용자 비율이나 사용 목적을 뜻하지 않습니다.
모임 비교는 33/51건과 2/7건의 초기 관측으로, 인과관계나 통계적 유의성을 주장하지 않습니다.
기록 중 미참여 성공률 13.2%는 원수치 2/7건과 맞지 않아 28.6%를 사용했습니다.
초기 측정 오류가 있던 모임 실험은 성과 수치에서 제외하고 측정 개선 과정만 설명합니다.
서비스 설명은 기존 https://www.ringout.my/ 를 참고했습니다.
Three.js로 숲의 원근 이동과 나무 상단 흔들림을 렌더링합니다. 서버 API는 사용하지 않습니다.
Pretendard Variable을 로컬 assets에서 제공합니다. 글꼴 라이선스는 assets/Pretendard-LICENSE.txt에 포함되어 있습니다.

## EC2 + Nginx

`npm run build` 후 `dist/` 내용 전체를 `/var/www/ringout_landing`에 복사하고,
예시 설정의 도메인을 변경해 Nginx에 적용합니다. Node/Python 실행 서버는 배포 시 필요 없습니다.
HTTPS 인증서는 실제 도메인과 배포 환경에서 별도 설정합니다.

## 스크롤 인트로와 빌드

검은 양쪽 문이 스크롤 진행률에 맞춰 열리고, 역방향으로 스크롤하면 닫힙니다. 바로 만나보기 버튼으로 건너뛸 수 있습니다. 동작 줄이기 설정에서는 인트로를 생략합니다. 캐릭터 WebM은 무음 자동 반복 재생합니다. 동작 줄이기 설정에서는 영상 재생을 중지합니다.

`npm run build`로 `dist/`에 정적 배포 파일을 생성합니다. EC2에는 dist의 내용 전체(assets 포함)를 배포하세요.

## 따라오는 씨앗 안내

캐릭터는 문과 분리된 고정 레이어로 유지됩니다. 스크롤에 따라 중앙에서 오른쪽 아래로 이동하며 서비스 소개, 이용 과정, 선택된 이야기 탭, 마지막 안내에 맞춰 말풍선이 바뀝니다. 설명 접기/보기로 말풍선을 숨길 수 있습니다. 동작 줄이기 설정에서는 문 연출과 영상 재생을 생략하고 안내 캐릭터는 유지합니다.

## 1차 프로토타입

- 검은 문이 열린 뒤 스크롤로 숲 사이를 통과하고 목적지 문구를 표시합니다.
- 제공된 나무 PNG 3종을 깊이별로 배치하고 상단 부분에 좌우 변형을 적용합니다.
- 숲 속 씨앗은 생성한 뒷모습, 도착 시 원본 영상에서 추출한 정면 이미지를 사용합니다.
- 안내 캐릭터·말풍선·버튼은 함께 드래그되며, 조작 종료 10초 뒤 지정 위치로 복귀합니다.
- `forest3d.js`: Three.js 장면 및 씨앗 이동·점프. `assets/three.module.js`: Three.js 0.170.0.
- `.env`, 인증서·개인키, 의존성 및 빌드 산출물은 Git에서 제외합니다. 브라우저에 비밀값을 넣지 마세요.

## 주황색 제품 디자인

제공된 SOCAR 디자인 참고 문서의 흰 배경·회색 본문·Pretendard·12/14/16px 모서리 원칙을 링아웃 주황색으로 적용했습니다. theme.css가 제품 UI 디자인을 관리하며, 기존 숲과 캐릭터 동작은 유지합니다.
